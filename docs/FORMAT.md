# Формат `.slate`

`.slate` — открытый формат обмена и резервных копий. Это обычный zip-архив
(UTF-8 имена), который можно распаковать любым архиватором. Основное хранилище
приложения — SQLite (`slate.db`), `.slate` не заменяет его, а переносит доску
между устройствами и служит резервной копией (D-006).

## Структура архива

```
board.json
assets/<sha256>
assets/<sha256>
...
```

- `board.json` — обязательный ровно один файл, JSON в кодировке UTF-8.
- `assets/<sha256>` — необязательные файлы ассетов. Имя файла — SHA-256 его
  содержимого в нижнем регистре hex (64 символа). Пишутся только ассеты,
  на которые ссылаются элементы доски.
- Других записей быть не должно: неизвестный путь считается ошибкой импорта.

## board.json

```json
{
  "format": "slate-board",
  "version": 1,
  "id": "…",
  "name": "Моя доска",
  "width": 1920,
  "height": 1080,
  "createdAt": 1730000000000,
  "updatedAt": 1730000000000,
  "elements": [
    {
      "elementId": "…",
      "elementType": "image",
      "data": { "x": 10, "y": 20, "width": 100, "height": 80,
                "assetId": "<sha256>", "mime": "image/png" },
      "addedBy": "",
      "updatedAt": 1730000000000
    }
  ]
}
```

| Поле | Тип | Смысл |
|---|---|---|
| `format` | строка | Всегда `slate-board`. |
| `version` | целое | Версия формата. Сейчас `1`. |
| `id` | строка | Исходный id доски; при импорте всегда заменяется новым. |
| `name` | строка | Название, пустое заменяется на «Без названия». |
| `width`, `height` | целые | Размер холста в px. |
| `createdAt`, `updatedAt` | целые | Миллисекунды epoch; при импорте заменяются текущим временем. |
| `elements` | массив | Элементы в том же JSON, что и в протоколе (`docs/PROTOCOL.md`). |

Изображения описываются ссылкой `data.assetId` (SHA-256) и `data.mime`.
Устаревшие доски с `data.imageData` (base64) при открытии переносятся в
`AssetStore`; при экспорте в архив попадает уже файл.

## Совместимость и проверки

- Версия обязательна. Версия `> 1` (файл из будущего) и `< 1` отвергаются с
  понятной ошибкой; ничего не импортируется.
- Импорт всегда создаёт **новую** локальную доску: существующие записи не
  перезаписываются, исходный id из файла не используется.
- Ассеты проверяются по SHA-256: имя записи должно совпадать с хэшем
  содержимого, иначе архив считается повреждённым.
- Защита от zip-slip: разрешены только `board.json`, каталог `assets/` и пути
  вида `assets/<64 hex>`. Абсолютные пути, `..`, обратные слэши и любые другие
  записи отвергаются.
- Защита от zip-бомб: не более 512 файлов, `board.json` ≤ 64 МиБ, один ассет
  ≤ 16 МиБ, суммарно распаковано ≤ 256 МиБ. Лимиты проверяются по мере
  чтения потока, а не после полной распаковки.
- Архив читается и проверяется целиком до записи в SQLite и `AssetStore`;
  при любой ошибке не остаётся ни доски, ни файлов ассетов.

## Открытие

- Из интерфейса: «Импорт…» в списке досок.
- Из командной строки и ассоциации файла: `slate /путь/доска.slate` или
  двойной клик. Файл импортируется до показа списка, новая доска выделяется и
  открывается.
