### Как проверить

```bash
# клиент: 11 тестов
JAVA_HOME=/usr/lib/jvm/openjdk17 ./mvnw -B clean verify

# сервер без MongoDB: 11 unit-тестов, интеграционные пропущены
JAVA_HOME=/usr/lib/jvm/openjdk21 ./mvnw -B -f java-collab/server/pom.xml clean verify

# сервер с MongoDB: 13 тестов, включая два интеграционных сценария
SLATE_INTEGRATION_TESTS=1 MONGO_DB=canvas_collab_test \
MONGO_URI=mongodb://localhost:27017 \
JAVA_HOME=/usr/lib/jvm/openjdk21 \
./mvnw -B -f java-collab/server/pom.xml verify
```

Локальный результат на 2026-11-22: клиент — 11/11, сервер с Mongo — 13/13,
сборки `clean verify` зелёные. Интеграционный тест создаёт пользователей,
доски и приглашения в `canvas_collab_test` и очищает её до и после прогона.
